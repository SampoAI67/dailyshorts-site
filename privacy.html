DailyShorts

Privacy policy

Last updated: 10 November 2026

DailyShorts is a personal tool used by a single person, its owner, to publish videos to their own YouTube channel and Google Drive. It has no other users.

Google data it accesses

When the owner signs in with Google, DailyShorts asks for these permissions and uses them only as described:

  • YouTube upload (youtube.upload): to upload the day's video to the owner's channel as a private, scheduled video.
  • YouTube read-only (youtube.readonly): to confirm which channel is signed in and check the status of its own uploads.
  • Google Drive, app files only (drive.file): to place the day's video and its text in a "DailyShorts" folder that the tool itself creates. It cannot see any other file in the Drive.

What it does not do

  • It does not collect, sell, share or transfer any personal data or Google user data to anyone.
  • It does not use Google user data for advertising, profiling or training AI models.
  • It does not read, change or delete videos, comments or files it did not create.

Storage and security

The only Google data stored is the sign-in token that lets the tool upload on the owner's behalf. It is kept encrypted in the owner's private Google Cloud project (Secret Manager) and on the owner's own computer, and is never shared.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token stops all uploads.

Google API Services

DailyShorts' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services and is bound by the YouTube Terms of Service and the Google Privacy Policy.

Contact
